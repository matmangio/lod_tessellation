# Dynamic LOD with Tessellation in OpenGL

The aim of this project is to try out different techniques for achieving **Dynamic Level of Detail** of curved models in a 3D scene using **Tessellation Shaders**, adapting their quality based on both the object's importance in the scene and the current computational stress of the machine with the hope of maintaining a steady framerate. These results will also be compared with the ones of traditional, discrete techniques for Level of Detail to ascertain whether the added complexity of these methods is really worth it.
